# Digital Hub

Digital Hub by Digital Hub.

## Installation

### Windows
1. Download the latest **`.exe`** installer from the [Releases page](https://github.com/digi-bulk-marketing/digital-hub/releases/latest).
2. Run the installer and follow the prompts.
3. Launch **Digital Hub** from the Start menu.

## Updates

Download the newest installer from the [Releases page](https://github.com/digi-bulk-marketing/digital-hub/releases/latest) and reinstall.
